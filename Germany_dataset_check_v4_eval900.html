Germany Check: Full Dataset, Species Counts, and Category Lookup

Author

GlobalGeoTree team

1 Purpose

This short diagnostic report checks Germany in the GlobalGeoTree observations file.

It answers three questions:

  1. How many observations are available for Germany?
  2. How many recorded species are available for Germany?
  3. How many Germany observations and species can be assigned to the dataset-defined categories Rare, Common, and Frequent?

The category check is especially important because the full observations dataset may not contain a Category column. In that case, this report uses the larger evaluation dataset GlobalGeoTree-10kEval-900.csv as a category lookup table.

6 Category source and lookup logic

The category variable is handled in this order:

  1. If the main observations file already contains category, use it directly.
  2. If the main observations file does not contain category, use the evaluation dataset as a lookup table.
  3. Prefer joining by species_key because it is more stable than species names.
  4. If species_key is not available, fall back to joining by level3_species.

The species catalog is not used to assign Rare, Common, or Frequent, because the catalog does not normally contain category labels. It is a taxonomy reference, not a category lookup.

11 Conclusion

This diagnostic report separates two questions that are easy to confuse:

  1. How many observations and species exist for Germany in the main dataset?
    This is calculated directly from the full observations file after filtering country_code == 'DE'.

  2. How many Germany observations and species have a known Rare, Common, or Frequent category?
    This depends on whether the main file contains category. If it does not, category can only be assigned to species that overlap with the eval lookup dataset.

Therefore, if the category comes from GlobalGeoTree-10kEval-900.csv, the Rare/Common/Frequent analysis is a matched-subset analysis, not a complete classification of all Germany species.
