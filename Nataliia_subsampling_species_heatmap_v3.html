GlobalGeoTree: Species Ranges and Country Observation Hotspots

Author

Nataliia / GlobalGeoTree team

1 Purpose

This report focuses on one component of the larger GlobalGeoTree project: subsampling, species spatial spread, category-level spatial spread, and within-country observation hotspots.

The original questions were:

  1. Do trees from one species grow in the same area? And from the same category?
  2. Where are trees located in a given country?

For a clearer visualization report, these are reformulated as:

RQ1. Species and category spatial concentration
Do observations of the same tree species tend to be geographically concentrated, and do dataset-defined categories such as Rare, Common, and Frequent differ in their spatial spread?

RQ2. Within-country observation hotspots
Where are tree observations concentrated within a selected country, and which species or categories dominate these hotspots?

Note

The Category variable is treated as a dataset-defined category, not automatically as ecological rarity. In the 10k evaluation sample, category values may partly reflect the sampling design.

2 Data preparation and subsampling

The full GlobalGeoTree dataset contains millions of observations. Rendering all records directly in a report can lead to slow computation and overplotted maps. Subsampling is therefore used to reduce the data to a manageable size while preserving the groups needed for the research questions.

For this analysis, the preferred sample is stratified by country, category, and species. This is more appropriate than a purely random sample because random sampling can overrepresent dominant countries, dominant sources, or very frequently observed species.

The cleaned observation dataset contains 9,930 records, 80 countries, and 90 observed species. The analytical sample used in this report contains 9,930 records.

3 Measuring species spatial spread

To evaluate whether observations of the same species occur in the same area, each species is summarized using three simple spatial indicators:

  • number of countries where the species is observed;
  • latitude range, measuring north–south spread;
  • median distance to the species center, measuring how far observations are from the species’ average location.

A species concentrated in one area should have a small number of countries and a smaller distance to its center. A widespread species should have larger values.

This plot directly addresses the first part of RQ1. Species do not all show the same spatial behavior: some are strongly localized, while others are distributed across many countries and over long distances.

4 Do categories differ in spatial concentration?

The next visualization compares species-level spatial spread across the dataset-defined categories. Each point is one species, so the viewer can see both the category medians and the variability inside each category.

This figure is useful because it avoids reducing the categories to only one number. If points within a category are widely spread vertically, then category membership alone is not enough to explain geographic range.

To make the spread metrics more intuitive, three example species are selected: one relatively localized species, one intermediate species, and one widespread species. These examples are chosen automatically from the species spread ranking.

8 Interpretation

The visual analysis suggests three important points.

First, species differ substantially in their observed spatial spread. Some species are concentrated in a small number of places, while others appear across many countries and at larger distances from their geographic center.

Second, the dataset-defined categories do not fully explain spatial range by themselves. If species within the same category show very different distances to their centers, then category membership should be interpreted carefully.

Third, within-country heatmaps show observation hotspots, but these hotspots should not be interpreted as pure ecological density. They also reflect observation effort, accessibility, platform usage, and the sampling design of the dataset.

9 Limitations

This analysis has several limitations:

  • The 10k evaluation sample is small relative to the full 6M dataset.
  • The Category variable is dataset-defined and should not automatically be interpreted as true ecological rarity.
  • Coordinate-based heatmaps show observation density, not true tree abundance.
  • The species center metric is a simplified geographic measure and does not account for natural range boundaries or habitat suitability.
  • The country heatmap does not include administrative boundaries in order to keep the report lightweight and avoid additional map dependencies.

sample_up_to_grouped <- function(data, n_per_group) {
  # Safer than slice_sample(n = min(n(), n_per_group)), because dplyr requires
  # the n argument to be a fixed numeric value rather than n().
  data |>
    group_modify(~ slice_sample(.x, n = min(nrow(.x), n_per_group))) |>
    ungroup()
}

# Measuring species spatial spread

To evaluate whether observations of the same species occur in the same area, each species is summarized using three simple spatial indicators:

-   **number of countries** where the species is observed;
-   **latitude range**, measuring north--south spread;
-   **median distance to the species center**, measuring how far observations are from the species' average location.

A species concentrated in one area should have a small number of countries and a smaller distance to its center. A widespread species should have larger values.

```{r species-spread-data}
haversine_km <- function(lon1, lat1, lon2, lat2) {
  r <- 6371
  to_rad <- pi / 180
  d_lat <- (lat2 - lat1) * to_rad
  d_lon <- (lon2 - lon1) * to_rad
  a <- sin(d_lat / 2)^2 + cos(lat1 * to_rad) * cos(lat2 * to_rad) * sin(d_lon / 2)^2
  2 * r * atan2(sqrt(a), sqrt(1 - a))
}

species_centers <- obs_sample |>
  group_by(level3_species, category, level1_family, level2_genus) |>
  summarise(
    n_observations = n(),
    n_countries = n_distinct(country_code),
    center_lon = mean(longitude, na.rm = TRUE),
    center_lat = mean(latitude, na.rm = TRUE),
    lat_min = min(latitude, na.rm = TRUE),
    lat_max = max(latitude, na.rm = TRUE),
    lon_min = min(longitude, na.rm = TRUE),
    lon_max = max(longitude, na.rm = TRUE),
    .groups = "drop"
  ) |>
  mutate(
    lat_range = lat_max - lat_min,
    lon_range = lon_max - lon_min
  )

species_spread <- obs_sample |>
  left_join(
    species_centers |>
      select(level3_species, category, center_lon, center_lat),
    by = c("level3_species", "category")
  ) |>
  mutate(
    distance_to_center_km = haversine_km(longitude, latitude, center_lon, center_lat)
  ) |>
  group_by(level3_species, category) |>
  summarise(
    median_distance_to_center_km = median(distance_to_center_km, na.rm = TRUE),
    mean_distance_to_center_km = mean(distance_to_center_km, na.rm = TRUE),
    max_distance_to_center_km = max(distance_to_center_km, na.rm = TRUE),
    .groups = "drop"
  ) |>
  left_join(species_centers, by = c("level3_species", "category")) |>
  filter(n_observations >= min_obs_per_species)
```

    count(level3_species, category, name = "observations") |>
    arrange(desc(observations)) |>
    slice_head(n = 12)

  ggplot(top_country_species, aes(x = reorder(level3_species, observations), y = observations, fill = category)) +
    geom_col(width = 0.7) +
    coord_flip() +
    scale_y_continuous(labels = comma_format()) +
    scale_fill_manual(values = category_palette) +
    labs(
      title = paste("Most observed species in", focus_country_name),
      subtitle = "Top species provide context for the country-level hotspot map.",
      x = NULL,
      y = "Observations",
      fill = "Category"
    )

# Interpretation

The visual analysis suggests three important points.

First, species differ substantially in their observed spatial spread. Some species are concentrated in a small number of places, while others appear across many countries and at larger distances from their geographic center.

Second, the dataset-defined categories do not fully explain spatial range by themselves. If species within the same category show very different distances to their centers, then category membership should be interpreted carefully.

Third, within-country heatmaps show observation hotspots, but these hotspots should not be interpreted as pure ecological density. They also reflect observation effort, accessibility, platform usage, and the sampling design of the dataset.

# Limitations

This analysis has several limitations:

-   The 10k evaluation sample is small relative to the full 6M dataset.
-   The `Category` variable is dataset-defined and should not automatically be interpreted as true ecological rarity.
-   Coordinate-based heatmaps show observation density, not true tree abundance.
-   The species center metric is a simplified geographic measure and does not account for natural range boundaries or habitat suitability.
-   The country heatmap does not include administrative boundaries in order to keep the report lightweight and avoid additional map dependencies.
